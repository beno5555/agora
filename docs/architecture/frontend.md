# Frontend (Angular)

The Angular app talks to the .NET API for everything off-chain, and to Solana directly through the user's wallet for everything involving money.

## Pages

| Route | Page | Main actions |
|---|---|---|
| `/` | Home: games, featured listings | browse |
| `/g/:slug` | Game storefront: listings for one game, filter by type | open a listing |
| `/l/:id` | Listing (**the deal link sellers share**): terms, deposits, seller's on-chain record | **Buy** → sign in if needed → `create_deal` |
| `/d/:id` | Deal page: status, timeline, countdowns, buyer note | buttons from `allowedActions`: accept, mark delivered, confirm N parts, dispute, offer/accept split, claim, refund, cancel |
| `/sell` | Create/edit a listing | |
| `/me` | Dashboard: my deals (buying/selling), my listings, notifications | |
| `/u/:wallet` | Public profile + reputation | |

The deal page is the heart of the demo. It should make "the money is locked" visible: a breakdown of the vault (payment + both deposits) and who gets what under each outcome.

## Wallet and sign-in
- **Phantom Connect** (email sign-in creates an embedded wallet; existing Phantom users connect directly). Packages and setup: https://docs.phantom.com/phantom-connect. Starter templates are linked from the event resources page.
- A `WalletService` wraps it: `connect()`, `publicKey`, `signMessage()`, `signAndSendTransaction()`.
- An `AuthService` runs the flow in [auth.md](auth.md) after connecting. The session cookie is sent automatically (`withCredentials`). An HTTP interceptor sends a 401 back to sign-in.

## Program client
- `@coral-xyz/anchor` + `@solana/web3.js`, using the IDL generated by the program (`src/app/solana/idl/agora.json`, copied after each program build).
- A `DealProgramService` has one method per instruction. Each builds the transaction with the accounts (PDAs worked out from the seeds in [program.md](program.md)), has the wallet sign and send it, waits for `confirmed`, then calls `POST /api/deals/{id}/sync`.
- Show the transaction signature with a Solana Explorer link (`?cluster=devnet`) after every action. Judges like seeing it on-chain.

## Things to check during setup
- Anchor's TS client and web3.js expect Node's `Buffer`. Add the `buffer` package and set `globalThis.Buffer` in `main.ts`.
- Phantom Connect's SDK may use a different Solana library (`@solana/kit`) than Anchor (`@solana/web3.js` v1). If so, have the wallet sign a serialized transaction and convert at the boundary.
- Format amounts with `mintDecimals` from `/api/config` and keep them as `bigint` or string internally.

## Dev setup
`ng serve` with `proxy.conf.json` mapping `/api` → `http://localhost:5107`, so cookies stay same-origin.
